# bench/umd — simulation benches

Icarus Verilog (`iverilog -g2012`). Every bench and runner follows the discipline
MiSTer_DVD earned the hard way (its `docs/hw_budget_and_lessons.md` §4 is the long form;
the rules are repeated in `CLAUDE.md` "Lessons carried from MiSTer_DVD"):

- **A runner `cd`s to the repository root** and every path is relative to it. `$readmemh`
  paths in the RTL assume the same.
- **Benches `$fatal(1)` on failure and print `PASS: <bench>` on success.** A `$finish` on
  the failure path exits 0 and a runner reads it as a pass. Runners require the PASS
  marker positively; they never score on the absence of "FAIL".
- **Score with `!==`, never `!=`.** An X passes `!=` vacuously. When a bench reports a count
  of zero for something that cannot be zero, suspect this first.
- **A new port on a shared module floats Z in every bench that instantiates it** without
  the port. Tie it off in every bench in the same commit.
- **`--red` proves the bench can fail.** Each runner applies deliberate mutations to a COPY
  of the shipping RTL (never the tree) and requires each to be caught by the arm written
  for it. A mutation nothing catches means the bench cannot see that defect; a mutation
  everything catches says nothing about which arm is load-bearing. Anchors are asserted
  unique so a moved line is a harness failure, not a silent no-op.
- **Golden models** live in `tools/*_ref.py` and are regenerated at run time, never
  committed as outputs. A model written from the RTL shares its bugs: prefer an
  independent oracle (ffmpeg, the JM reference decoder, the spec) where one exists.
- **Fixtures** are one hex byte per line (`$readmemh`), with a `<stem>.meta.hex` beside them
  for parameters. Slices cut from local media by `tools/umd_fixture.py` go to
  `bench/umd/fixtures/gen/` (gitignored). Never commit commercial media whole. Two kinds,
  word orders in the tool's header: EP-aligned pack cuts (`--clip N --pts A B`, for the
  demux benches) and the `--nav` sparse image for the P2 reader bench (`.hex` sectors +
  `.lba.hex` map, `.reg.hex` regions with their dependency masks, `.sseq.hex` stream
  order, `.exp.hex`/`.title.hex`/`.lang.hex` expected outputs, and since P6b2 the
  navigation script `.nav.hex` with the streams its seeks must produce, `.nseq.hex`; synthetic images for the
  edges no disc has come from `tools/umd_reader_cases.py`). The CABAC engine's sets
  (`tools/cabac_vectors.py`: `.bytes`/`.req`/`.exp`/`.ctx`/`.meta.hex`) are random, not
  media, and regenerated by the runner. Goldens for them come from
  `tools/psmf_ref.py`, `tools/umd_clpi.py` and friends, regenerated at run time.
- **Scratch** (`.sim/`) is gitignored. Compiled sims, logs and rendered `.ppm` frames go there.
- **Two iverilog papercuts** (`plane_tb`): a string built inline in a `$readmemh` / `$fopen`
  argument (`{dir, $sformatf(...)}`, or a ternary of strings) crashes the compiler in
  `eval_vec4.c`; build it into a `string` variable first. `$fscanf` into a 2-D `int` array
  refuses its later arguments as "not assignable": read one `%d` at a time into a scalar.
